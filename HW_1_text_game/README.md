# HW 1 — Текстовая игра

Первое домашнее задание курса VK Education «Разработка веб-сервисов на Golang».

## 📌 Описание

Консольная текстовая игра на Go, в которой игрок перемещается между комнатами, взаимодействует с предметами и выполняет действия для достижения цели.

**Цель игры:** собрать необходимые вещи, открыть дверь и выйти из дома.

## ⚙️ Возможности

- Перемещение между комнатами.
- Осмотр окружения и доступных предметов.
- Подбор предметов и управление инвентарём.
- Надевание рюкзака.
- Применение предметов к объектам.
- Проверка условий для выполнения действий.
- Изменение состояния игрового мира.

## 🧩 Используемые возможности Go

- Структуры и методы.
- Указатели.
- Слайсы и map.
- Условные операторы и циклы.
- Работа со строками.
- Стандартная библиотека Go.

## 🚀 Запуск

Из папки с домашним заданием:

```bash
go run main.go
```

Запуск тестов:

```bash
go test -v
```
