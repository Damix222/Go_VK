# HW2 — Конвейерная обработка писем

Второе домашнее задание курса VK Education **«Разработка веб-сервисов на Golang»**.

## 📌 Описание

Реализация конкурентного конвейера обработки электронных писем на Go.

Программа получает пользователей по email, собирает их сообщения, проверяет сообщения на спам и формирует отсортированный результат.

Основная цель задания — научиться использовать горутины, каналы и механизмы синхронизации для параллельной обработки данных.

## ⚙️ Этапы конвейера

**1. `RunPipeline`**

Организует взаимодействие этапов конвейера через каналы. Каждый этап запускается в отдельной горутине.

**2. `SelectUsers`**

Получает пользователей по email с помощью `GetUser()`. Запросы выполняются параллельно, а дубликаты пользователей удаляются по ID.

**3. `SelectMessages`**

Получает сообщения пользователей через `GetMessages()`. Пользователи объединяются в группы максимум по два человека. Группы обрабатываются параллельно.

**4. `CheckSpam`**

Проверяет сообщения через `HasSpam()`. Буферизированный канал используется как семафор, ограничивающий количество одновременных проверок до пяти.

**5. `CombineResults`**

Собирает результаты и сортирует их: сначала спам, затем обычные сообщения. Внутри каждой группы сообщения упорядочиваются по возрастанию ID.

## 🛠️ Использованные технологии

- **Goroutines** — параллельное выполнение операций.
- **Channels** — передача данных между этапами.
- **sync.WaitGroup** — ожидание завершения горутин.
- **sync.Mutex** — защита общих данных от конкурентного доступа.
- **Buffered channels** — ограничение конкурентности через семафор.
- **sort.Slice** — сортировка результатов по нескольким условиям.

## 🧪 Тестирование

Запуск тестов из папки домашнего задания:

`go test -v`

Проверка на гонки данных:

`go test -race`

Для работы `-race` на Windows требуется совместимый 64-битный C-компилятор.
